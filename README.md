# GreenSteps — Community Sustainability Tracker

A responsive sustainability dashboard for tracking community eco-actions, logging clean-up/recycling/tree-planting activities, and viewing progress. Demo data is stored in localStorage.

## Features
- Responsive layout for desktop and mobile
- Working form to add new entries
- Category filtering and remove actions
- Dashboard counters update automatically
- Browser `localStorage` persistence
- Sample data included so the demo is populated on first launch

## Tech stack
HTML5 · CSS3 · Vanilla JavaScript

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add entries, filter the list, refresh the page, and confirm entries persist.

No build tools or API keys are required.

## Deploy with GitHub Pages
1. Create a public GitHub repository and upload `index.html`, `style.css`, `script.js`, and this README.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for the Pages deployment to finish; GitHub will display the live URL in the Pages section.

This is a student-built community-impact prototype. It demonstrates a way to coordinate neighbourhood support / sustainability activities. It is not connected to a real organization, and sample impact figures are illustrative.
